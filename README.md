Personal portfolio website — [cloudxdam.github.io/portfolio](https://cloudxdam.github.io/portfolio/)

Static site presenting my projects, tech stack and contact info.
Available in **Spanish** (root) and **English** (`/en/`).

## Structure

- `index.html` — Spanish version
- `en/index.html` — English version
- `css/`, `js/`, `assets/` — styles, scripts and icons
- `docs/` — CVs (Spanish and English, Harvard format)

## Stack

Plain HTML5, CSS3 and JavaScript — no frameworks, no build step.

## Deployment

Published automatically with GitHub Pages from the `main` branch.

## Localization

Both pages declare `hreflang` (es / en / x-default) and include an
ES | EN switcher in the navigation.
