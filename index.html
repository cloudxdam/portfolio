Proyectos

RestoReserve API

API REST desarrollada con Java y Spring Boot para la gestión de mesas y reservas en restaurantes.
Implementa autenticación y autorización mediante JWT y Spring Security, gestión de usuarios y roles, validación de datos, reglas de negocio para reservas y manejo global de excepciones.
El proyecto está estructurado siguiendo una arquitectura por capas (Controller, Service, Repository) y utiliza Spring Data JPA, H2, Maven y OpenAPI/Swagger. Incluye además pruebas automatizadas con JUnit 5 y Mockito.

Java Spring Boot Spring Security JWT Spring Data JPA H2 Maven OpenAPI/Swagger JUnit 5 Mockito

FishingConditions

Aplicación Android desarrollada en Java para consultar las condiciones de pesca de diferentes zonas costeras de Tenerife.
Integra datos meteorológicos, estado del mar, mareas y fase lunar mediante varias APIs externas, y los combina para calcular una puntuación de pesca personalizada de 0 a 100.
Utiliza Room para almacenar localmente los datos de mareas y reducir peticiones repetidas, además de incluir pruebas unitarias para la lógica de cálculo y formateo, permitiendo detectar y corregir errores durante el desarrollo.

Java Android Retrofit Gson OkHttp Room Gradle Material Components REST APIs JUnit
Ver código en GitHub

QubeCore

Aplicación web desarrollada en el marco de un proyecto eTwinning del programa Erasmus+ de la Comisión Europea, realizado en colaboración entre el CIFP Adeje y la startup QubeCore de la Mazowieckie Technikum Innowacji en Płocku, Polonia.
El proyecto combina un frontend desarrollado con React y Vite con una API backend desarrollada con Spring Boot, incorporando autenticación mediante JWT, persistencia de datos con MySQL y ejecución del entorno mediante Docker.
La experiencia permitió trabajar en un proyecto tecnológico real dentro de un equipo internacional y aplicar conocimientos de desarrollo frontend y backend.

React 19 Vite Tailwind CSS Java Spring Boot MySQL Docker JWT
