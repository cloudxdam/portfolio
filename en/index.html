Projects

RestoReserve API

REST API built with Java and Spring Boot for restaurant table and reservation management.
Implements authentication and authorization with JWT and Spring Security, user and role management, data validation, reservation business rules and global exception handling.
The project follows a layered architecture (Controller, Service, Repository) and uses Spring Data JPA with H2 (default profile) and PostgreSQL on Docker (postgres profile), Maven, OpenAPI/Swagger and CI with GitHub Actions. Includes 24 automated tests with JUnit 5, Mockito and MockMvc.

Java Spring Boot Spring Security JWT Spring Data JPA H2 PostgreSQL Maven OpenAPI/Swagger JUnit 5 Mockito Docker GitHub Actions

FishingConditions

Android application developed in Java to check fishing conditions at different coastal spots in Tenerife.
Combines weather data, sea state, tides and moon phase from several external APIs, and blends them into a custom 0–100 fishing score.
Uses Room to store tide data locally and reduce repeated requests, and includes unit tests for the calculation and formatting logic, allowing bugs to be caught and fixed during development.

Java Android Retrofit Gson OkHttp Room Gradle Material Components REST APIs JUnit
View code on GitHub

QubeCore

Web application developed as part of an eTwinning project in the European Commission's Erasmus+ program, carried out jointly between CIFP Adeje and the QubeCore startup from Mazowieckie Technikum Innowacji in Płock, Poland.
The project combines a React and Vite frontend with a Spring Boot backend API, featuring JWT authentication, MySQL persistence and a Dockerized environment.
The experience meant working on a real tech project within an international team and applying both frontend and backend development skills.

React 19 Vite Tailwind CSS Java Spring Boot MySQL Docker JWT
